# Фотографии

Положите сюда снимки из макета:

| файл | где используется | требования |
|---|---|---|
| `hero.jpg` | первый экран | горизонтальный, ≥2000px по ширине; в код добавлен grayscale-фильтр, цветной оригинал не нужно обесцвечивать заранее |
| `team.jpg` | секция «Кто мы» | групповой снимок, ≥1800px |
| `login.jpg` | экран входа | **без лиц в центре кадра** — карточка формы ложится ровно туда, и взгляд уходит на человека, а не на кнопку |

Все три прогоняются через затемнение (`MediaPanel`), поэтому светлые
кадры допустимы — контраст текста обеспечивается слоем, а не фотографией.

Перед сборкой сожмите: страница почти целиком из фото на полный экран,
без оптимизации она грузится десяток секунд. Достаточно WebP с качеством
80–85 и шириной 2000px.
